Alur Kerja
    
      
  1. Content Planner → Generate ide baru (status 'Ready') atau isi langsung di Google Sheets.
    2. 
      
  2. Dashboard → Start Automation. Bot membuat video dan mengubah status menjadi 'Ready for Review'.
    3. 
      
  3. Video Studio → Generate SEO / Variasi Judul, cek skor & audit SEO, atur kategori/privasi/jadwal, pilih platform tujuan (YouTube, TikTok, Instagram, Facebook), lalu Publish.
    4. 
      
  4. Setelah upload ke YouTube, status berubah menjadi 'Done' dan link tersimpan di kolom Output. TikTok / Instagram / Facebook masih simulasi: tidak ada data yang dikirim, status baris tidak berubah, hasilnya tercatat di Riwayat publish.

    
Shortcut Keyboard (Ctrl / Alt / ⌘)
    
      
  • K Fokus pencarian (Enter = buka Planner, Esc = hapus filter)
    • 
      
  • R Refresh data dari Google Sheets
    • 
      
  • B Kecilkan / perluas sidebar
    • 
      
  • 1…4 Dashboard / Planner / Video Studio / Akun (gunakan Alt jika browser memakai Ctrl+angka)

    
Pemecahan Masalah
    
      
  • 'Gagal mengambil data Google Sheets' → cek internet, client_secret.json, dan nama sheet.
    • 
      
  • Tombol Publish nonaktif → file video di kolom Output tidak ditemukan atau status bukan 'Ready for Review'.
    • 
      
  • Ubah Log Level ke 'Debug' di Settings untuk melihat traceback lengkap.
    • 
      
  • Generate SEO tidak jalan → pastikan modules/youtube_uploader.py bisa dimuat (lihat Live Log).
    • 
      
  • Login YouTube salah akun → Akun → Switch / Reset Akun YouTube.
    • 
      
  • Platform tampak abu-abu / tidak bisa dipilih di Video Studio → hubungkan dulu di menu Akun.
    • 
      
  • Uji jalur error platform dummy: set env SOCIAL_DUMMY_FAIL=tiktok lalu restart server.
